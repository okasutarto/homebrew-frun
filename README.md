# Okasutarto Frun

## How do I install these formulae?

`brew install okasutarto/frun/<formula>`

Or `brew tap okasutarto/frun` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "okasutarto/frun"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
